7. How to turn on live login (do not seed)

The live API is empty of demo passwords on purpose. Create one super admin, then set the Lunar owner password. After the admin exists, delete ADMIN_BOOTSTRAP_KEY from Render.

7.1 Copy the bootstrap key

  1. Open Render → service orvexa-api → Environment.
  2. Copy ADMIN_BOOTSTRAP_KEY (Render generated this; it is not the published string orvexa_bootstrap_2026).

7.2 Create the first super admin (PowerShell)

$env:API_BASE = "https://orvexa-api-nskw.onrender.com"
$env:ADMIN_BOOTSTRAP_KEY = "<paste from Render>"
$env:ADMIN_EMAIL = "hello@orvexatech.com"
$env:ADMIN_PASSWORD = "<at least 12 characters you choose>"
$env:ADMIN_NAME = "Orvexa Super Admin"
$env:CONFIRM_PRODUCTION_BOOTSTRAP = "yes"
npm run admin:bootstrap

Success is HTTP 201. HTTP 409 means an admin already exists — skip to 7.3 and sign in with that account. HTTP 403 means the key is wrong.

7.3 Set the Lunar seller password

$env:API_BASE = "https://orvexa-api-nskw.onrender.com"
$env:ADMIN_EMAIL = "hello@orvexatech.com"
$env:ADMIN_PASSWORD = "<the admin password from 7.2>"
$env:STORE_SLUG = "lunar"
$env:SELLER_PASSWORD = "<at least 8 characters you choose>"
npm run seller:set-password

Then sign in:

  • Admin: https://orvexa-cloud.pages.dev/ with the email and password from 7.2
  • Seller: https://orvexa-cloud.pages.dev/t/lunar/dashboard as gowreesh@thelunarclothing.com with the password from 7.3
Do not write those live passwords into this PDF or into git. After 7.2 succeeds, delete ADMIN_BOOTSTRAP_KEY on Render so nobody can create a second first-admin.
